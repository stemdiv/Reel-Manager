Mode d'emploi & FAQ

Guide complet de toutes les fonctionnalites

Dashboard

Overview of your library: playlist counts, video totals, public/private breakdown, top playlists, and quick actions.

Search

Search across ALL playlists at once. Type a title and get instant results with source playlist info.

Discover

Search YouTube by topic and create a playlist from the top results. Costs ~100 quota units per search.

Merge

Combine multiple playlists into one. Select sources, name the destination, and consolidate.

Move videos

Copy or move videos between playlists. Pick a source, select videos, choose a destination.

Ghost videos

Detect and remove deleted, private, or unavailable videos from your playlists.

Duplicates

Find videos that appear in multiple playlists. Great for deduplication and cleanup.

Statistics

Advanced charts and data about your YouTube library: trends, distribution, detailed analytics.

Tags

Categorize playlists with custom tags. Use auto-categorization for fast organization.

Folders

Organize playlists in nested folders. Create hierarchies like Tech > Frontend > React.

Deck

Multi-column view. Display multiple playlists side by side with horizontal scroll.

Watch Plan

Build a custom watch session with selected videos. Shows total duration and launches a viewing queue.

Playlist Diff

Compare two playlists: shared videos, unique to each, and comparative stats.

Bulk Rename

Mass-rename playlist titles. Add prefixes, suffixes, or find-and-replace across playlists.

Backup / Restore

Save your playlist structure as JSON and restore it anytime to protect your content.

Export

Download your full library in CSV or JSON for external analysis or backup.

Keyboard shortcuts

Ctrl+K Search Ctrl+B Backup Esc Close modals

API Quota

YouTube API is limited to 10,000 units/day. Reads cost 1 unit, writes cost 50. Check the quota counter in the header.

YouTube Music

YouTube Music shares the same playlist library as YouTube. All changes made here will be reflected in YouTube Music and vice-versa.
